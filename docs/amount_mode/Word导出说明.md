# 全部分组导出 Word

完成安装后双击项目根目录的 `start-amount.cmd`。有完整打包目录时也可打开 `dist-amount-word\AmountTool\AmountTool.exe`。

1. 生成完成后进入“分组结果”，或在“历史”中打开一个已完成且复核通过的批次。
2. 点击“导出本批全部分组为Word”，选择保存位置和新文件名。
3. 等待“Word导出完成”提示，提示中会显示全部组数和文件位置。

工具页也有“导出所选批次全部分组为Word”。每次导出所选批次的所有组，包含第一组到最后一组，与当前显示的组号和历史分页无关。

文档按既有结果顺序排列，使用“第一组、第二组……”标题，标题后紧接原有直选正文，组与组之间一个空行。三位号码的前导零、号码顺序、直选金额均保留。不会重新生成、洗牌、合并或计算金额。

导出只从已完成且原核查证据有效的固定批次读取内容，不向固定批次目录写 Word。采用同目录临时文件，实际 Word 逐段回读与完整原结果比较，核对组数及最后一组；发布前后复验原数据和原核查证据。失败或取消不会留下正式完成文件，已有文件拒绝覆盖，请改用新的文件名。

该功能只需程序自身，导出不要求安装 Word 或 WPS。打开文档需要支持 `.docx` 的软件。

导出测试见 `tests/amount_mode/test_word_export.py`，覆盖完整正文、万组以上的尾组、前导零、金额差异、缺组、取消、已有目标保护及原核查证据变化。发布后的实际大批次核对记录保留在运行设备本地，不随源码公开上传。
